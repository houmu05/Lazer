# Lazer v0.1.1-beta.1

首个 beta：资料库专辑可以自己排序了，「我喜欢的音乐」也能按名字排。

## 新增

- **资料库 → 专辑 支持长按拖动排序**：长按卡片（桌面端鼠标直接拖）抬起后预览落位，
  松手保存；未自定义过的专辑保持服务端顺序排在后面，新收藏的专辑不会因为排序而消失。
  排序存在本机（`lazer_album_order`），与歌单排序共用同一套拖拽交互。
- **「我喜欢的音乐」支持按歌曲名称 / 歌手名称排序**：歌曲标题右侧新增排序菜单
  （默认顺序 / 歌曲名称 / 歌手名称），排序同时作用于列表、播放队列、定位与下载；
  同名同歌手时保持收藏时间顺序，不会每次刷新乱跳。选择保存在 `lazer_liked_sort`。

## Windows

- 新增 **MSI 安装包**（`Lazer-Windows-x86_64.msi`）：开始菜单快捷方式、卸载项、
  覆盖安装自动升级；原来的 ZIP 继续作为免安装版提供。

## 说明

- 这是预发布版本（beta），只从 `master` 的稳定代码 + `nextgen` 的预览改动构建；
  验证通过后会以正式版本（不带 `-beta`）发布。
- 安装包未做代码签名，Windows SmartScreen 可能提示；选择"仍要运行"即可。
