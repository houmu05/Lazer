# Lazer v0.1.1-beta.2

修复 beta.1 的两个可见问题，功能不变。

## 修复

- **「我喜欢的音乐」排序菜单在所有入口都能看到**：beta.1 只有从「我喜欢」页面进入时
  才显示排序按钮；从桌面侧边栏歌单列表点进同名收藏时没有。现在只要打开的是喜欢集合，
  无论入口，歌曲标题右侧都会出现排序菜单（默认顺序 / 歌曲名称 / 歌手名称）。
- **顶部歌曲数与列表一致**：列表用实际加载到的曲目数，而头部之前显示账号摘要里可能
  过期的收藏数（例如显示 1163 首、列表 1164 首）。现在头部优先使用已加载行数。

## 说明

- Windows 安装包与免安装 ZIP、Linux AppImage、Android APK 与 beta.1 的形态一致；
  MSI 未签名，SmartScreen 可能提示"仍要运行"。
- 验证通过后会以正式版本（不带 `-beta`）发布。
